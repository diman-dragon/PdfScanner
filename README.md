# PDF Сканер 2.0.2

Android-приложение: сканирование документов в PDF.
Kotlin + Jetpack Compose + Material 3 + Room. minSdk 26.

## Возможности
- Два режима: одиночный скан (одна страница, один PDF) и пакетный (несколько страниц в один PDF, пауза до следующей по умолчанию 5 с, завершить можно в любой момент). Сканер Google: камера, обрезка, выравнивание перспективы.
- Раздельные настройки приложения и сканирования.
- Автоулучшение: убирает тени и затемнения у сгибов, баланс белого, режимы «Документ», «Чёрно-белый», «Оригинал».
- OCR на устройстве (Tesseract, rus + eng): PDF с текстовым слоем, поиск по документам, копирование текста.
- Редактор страниц: порядок, поворот, удаление, добавление.
- Объединение PDF, сохранение в выбранную папку с правкой имени, «Поделиться».
- Светлая/тёмная тема, настройки, подготовка к публикации в Google Play.

## Как получить APK
1. Создайте репозиторий на GitHub, закоммитьте и запушьте содержимое этой папки.
2. Вкладка **Actions** → «Build debug APK» (3–8 минут).
3. APK: **Actions → запуск → Artifacts** или, на ветке `main`/`master`, **Releases → Debug build**.
4. Установите на телефон (разрешите установку из неизвестных источников).

Debug-ключ лежит в репозитории (`app/debug.keystore`), новый APK ставится поверх старого.
