# PDF Сканер 2.0.1

Android-приложение: сканирование документов в PDF.
Kotlin + Jetpack Compose + Material 3 + Room. minSdk 26.

## Возможности
- Собственная камера (CameraX) вместо окна Google: поиск границ документа, автоснимок без кнопки, выравнивание перспективы.
- Два режима: одиночный (один кадр, проверка, «Готово» или «Удалить») и пакетный (после каждой страницы пауза, по умолчанию 5 с, затем камера снимает следующую сама).
- Границы: автоматически на каждом кадре или «свои»: выставляете углы один раз на первом снимке, дальше всё применяется само. Углы можно поправить пальцем на любом снимке.
- Импорт готовых фото из галереи, добавление страниц в существующий документ.
- Раздельные настройки приложения и сканирования.
- Автоулучшение: убирает тени и затемнения у сгибов, баланс белого, режимы «Документ», «Чёрно-белый», «Оригинал».
- OCR на устройстве (Tesseract, rus + eng): PDF с текстовым слоем, поиск по документам, копирование текста.
- Редактор страниц: порядок, поворот, удаление, добавление.
- Объединение PDF, сохранение в выбранную папку с правкой имени, «Поделиться».
- Светлая/тёмная тема, настройки, подготовка к публикации в Google Play.

## Как получить APK
1. Создайте репозиторий на GitHub, закоммитьте и запушьте содержимое этой папки.
2. Вкладка **Actions** → «Build debug APK» (3–8 минут).
3. APK: **Actions → запуск → Artifacts** или, на ветке `main`/`master`, **Releases → Debug build**.
4. Установите на телефон (разрешите установку из неизвестных источников).

Debug-ключ лежит в репозитории текстом (`app/debug-keystore.b64`), поэтому каждый новый APK подписан одним и тем же ключом и ставится поверх старого без удаления. В логе сборки печатается отпечаток подписи (шаг «Отпечаток подписи APK»): он должен совпадать во всех сборках.

## Если git ругается на конфликт тегов (latest)
Старые версии workflow каждый раз пересоздавали тег `latest`. Один раз выполните локально:
```
git tag -d latest
git pull
```
(или `git fetch --tags --force`). Дальше тег больше не меняется.
